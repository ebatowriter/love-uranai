# パブリックスタンド × 占いサービス - ペライチLP

飲食店兼バーとして運用しているパブリックスタンドに占いサービスをマッチさせた、モダンなペライチ（ワンページ）ランディングページです。

## 🎨 デザイン特徴

- **ベースカラー**: #eb3474 (鮮やかなピンク)
- **スタイル**: モダン、神秘的、親しみやすい
- **レスポンシブ対応**: PC、タブレット、スマートフォン対応
- **アニメーション**: CSS3によるスムーズなアニメーション効果

## 🔗 WordPressでの使用方法

### 方法1: カスタムHTMLブロックを使用（推奨）

1. WordPress管理画面でページまたは投稿を編集
2. 「+」ボタンをクリックして新しいブロックを追加
3. 「カスタムHTML」ブロックを選択
4. `wordpress-custom.html`の内容をコピー＆ペースト
5. ページを保存・公開

### 方法2: ページテンプレートとして使用

1. 使用中のテーマディレクトリに`page-mystic-pub.php`を作成
2. `index.html`の内容をPHPテンプレートに組み込み
3. 新しいページを作成し、テンプレートを適用

### 方法3: ショートコードとして実装

1. functions.phpにショートコード関数を追加
2. HTMLとCSSをPHP関数内に組み込み
3. `[mystic-pub-lp]`ショートコードで呼び出し

## 📞 サポート

### よくある問題と解決策

**Q: WordPressでスタイルが適用されない**
A: テーマのCSSと競合している可能性があります。`.mystic-pub-lp`クラスの詳細度を上げるか、`!important`を追加してください。

**Q: フォームが動作しない**
A: WordPressのセキュリティ設定やプラグインがJavaScriptを制限している可能性があります。管理者に確認してください。

**Q: モバイルでレイアウトが崩れる**
A: ビューポートメタタグが設定されているか確認してください。また、親テーマのCSSが影響している可能性があります。
