パブリックスタンドが運営する無料オンライン占い診断サービスのペライチ（ワンページ）ランディングページです。

## 🔮 サービス概要

### コンセプト
- **運営**: パブリックスタンド株式会社
- **サービス**: 無料オンライン占い診断
- **対象ユーザー**: 占いに興味がある全ての方
- **特徴**: 完全無料・24時間利用可能・個人情報不要

## 🎮 占い診断の使い方

### タロット占い
1. 占いたい内容を選択（恋愛・仕事・総合運）
2. 5枚のカードから1枚を選択
3. 「占い結果を見る」をクリック
4. 選んだカードの意味とアドバイスを表示

### 星座占い
1. 星座を選択
2. 自動的に今日の運勢を表示
3. エレメント・ラッキーポイント・アドバイスを確認

### 水晶玉クイック占い
1. ヒーローセクションの水晶玉をクリック
2. 今日のランダム運勢を表示
3. ラッキーカラー・ラッキーナンバーも表示

## 💡 カスタマイズ方法

### 占いデータの追加・変更
```javascript
// js/fortune-script.js の fortuneData オブジェクトを編集
const fortuneData = {
    tarot: {
        cards: [
            // 新しいカードデータを追加
            { name: "新カード", advice: "アドバイス...", ... }
        ]
    }
};
```

### 色の変更
```css
/* CSS変数（:root セクション）で統一変更 */
:root {
    --primary-color: #eb3474;    /* メインカラー */
    --accent-purple: #9b59b6;    /* アクセントカラー */
    /* ... */
}
```

### 新しい占い種類の追加
1. `fortuneData` に新しい占いデータを追加
2. `startFortune()` 関数にcase文追加  
3. 専用の実行関数を作成
4. HTMLにサービスカード追加
